# Simple Omelette Recipe

A responsive **recipe page** built with HTML and CSS as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

The goal of this project was to recreate the provided recipe design as accurately as possible while practicing semantic HTML, responsive layouts, typography, spacing, lists, and structured content.

## 🧩 Challenges

One of the main challenges was organizing the different sections of the recipe while keeping the page visually balanced.

Unlike smaller component-based challenges, this project contains several content-heavy sections, including preparation information, ingredients, instructions, and nutrition details. Each section needed consistent spacing, typography, and hierarchy.

Another challenge was making sure the layout remained readable and visually close to the reference design across different screen sizes.

I overcame these challenges by breaking the page into smaller semantic sections and styling each part individually. I also used responsive CSS and Flexbox to help maintain the layout across different viewport sizes.

## ♿ Accessibility

The project uses semantic HTML elements and appropriate list structures for the ingredients and instructions.

The recipe content is organized into meaningful sections to make the page easier to understand and navigate.

Accessibility is something I want to continue improving as I build more projects, especially through better keyboard navigation, focus states, and semantic structure.
